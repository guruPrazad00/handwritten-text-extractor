# Text Extractor

AI-powered handwritten text extraction web application built using Flask, OpenCV, and OCR.Space API.

---

## Features

- Handwritten text extraction
- AI-style reconstructed overlay
- Drag & drop image upload
- Download enhanced image
- Modern responsive UI
- OCR-based handwritten text recognition

---

## Tech Stack

- Flask
- OpenCV
- OCR.Space API
- HTML
- CSS
- JavaScript

---

## Installation

Clone the repository:

```bash
git clone https://github.com/guruPrazad00/handwritten-text-extractor.git
```

Open project folder:

```bash
cd handwritten-text-extractor
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
